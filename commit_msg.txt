fix: remove CSP and COOP headers that blocked JS in production

CSP with unsafe-inline is incompatible with Next.js production builds
because Next.js generates inline scripts with specific nonces/hashes.
The CSP was silently blocking script execution causing NO_FCP on
PageSpeed Insights / Lighthouse.

Also removed Cross-Origin-Opener-Policy: same-origin which can
interfere with Google Analytics measurement.

Kept safe headers: HSTS, X-Content-Type-Options, X-Frame-Options,
Referrer-Policy, Permissions-Policy.
